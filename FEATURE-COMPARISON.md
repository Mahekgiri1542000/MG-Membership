# MG Membership vs. the 15 "best WordPress membership plugins"

_Compared against the features listed for each plugin in Hostinger's article "15 Best WordPress Membership Plugins" (dated 28 Apr 2025, read 17 Nov 2026). Competitors' features are as the article describes them; their prices and features may have changed since._

**Legend:** ✅ included and tested · 🟡 partly covered (see note) · ❌ not included

## Summary

- MG Membership now covers **every core membership feature** the article lists across all 15 plugins: levels, recurring billing, content rules, drip, coupons, courses, corporate accounts, menus, files, pay-per-post, directory, custom fields, approval, reports, webhooks and more.
- **12 add-ons were added in this round** to close the gaps: Custom Fields, Member Approval, Menu Visibility, Protected Downloads, Pay-Per-Post, Member Directory & Profiles, Membership Automation, Webhooks & Integrations, Activity Log, Import Members, Account Sharing & Privacy, plus scheduled-release drip.
- **Not built** (they need third-party services or other products): social login, affiliate program, WooCommerce product sales/discounts, subscription proration, LMS assignments, and BuddyPress/bbPress integration. See [Not included](#not-included-and-why).
- **Beyond the 15:** Seminars & events with tickets and check-in, certificates with verification, signed Stripe webhooks, a login limit against account sharing, and visibility controls inside Elementor, Gutenberg, Divi, WPBakery and Beaver Builder.

## Extra features none of the 15 list

| Feature | Why it helps |
|---|---|
| **Seminars & events** with capacity, waitlist, member-only or paid tickets, check-in by ticket code, `.ics` calendar files, 24-hour reminders | Run webinars and workshops without another plugin |
| **Login limit** (max simultaneous logins) | Stops members sharing one account |
| **Hide locked content from search** | Visitors don't find titles they can't open |
| **Visibility controls inside page builders** (Elementor sections, any Gutenberg block, Divi/Beaver via CSS class) | Show parts of any page to members, non-members or guests |
| **Signed Stripe webhooks** with idempotent renewals | Renewals are recorded once, even when Stripe retries |
| **Certificate verification page** | Anyone can check a certificate code |
| **Course-completed email** with certificate link | Celebrates progress automatically |
| **Printable receipts** | Members can print or save invoices |
| **Magic-link login** (single-use, 15 min) | Members who forget passwords get in without a reset |
| **Login brute-force lockout + rate limits** | Stops password guessing and coupon guessing |
| **GDPR export / erase** (account Privacy tab + WordPress tools) | Members manage their own data; you stay compliant |
| **Renewal reminder 3 days before a charge** | Fewer surprise-charge disputes and refunds |
| **Private admin notes on members** | Support history in one place |
| **Independent security audit** with 44 attack tests | See SECURITY-REPORT.md |

## Not included, and why

| Feature | Reason / workaround |
|---|---|
| Social login (Google, Facebook…) | Needs OAuth apps per provider; use a dedicated social-login plugin alongside |
| Affiliate program | A separate product category; works alongside AffiliateWP or similar via webhooks |
| WooCommerce product sales & member discounts | WooCommerce isn't installed on this site to build and test against; good next add-on |
| Braintree gateway | Stripe already covers cards, Apple Pay and Google Pay |
| Subscription proration on upgrade | Upgrades currently end the old plan; proration needs per-gateway logic |
| Upsells / one-click purchase | Possible future add-on |
| LMS assignments (file submissions) | Possible future addition to the Courses add-on |
| BuddyPress / bbPress | Not installed here; could be added as an integration |
| Rule "by author" | Small addition if needed |
